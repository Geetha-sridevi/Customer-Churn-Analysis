# Customer Churn Analysis — Business Analyst Portfolio Project

## Purpose
A beginner-friendly project package that combines SQL, Excel, Power BI, business documentation, Agile planning, Scrum sprint artifacts, and a Jira task-board setup guide.

**Important:** Jira cannot be operated from this ZIP itself. Follow `jira/jira_setup_guide.md` to create the board and tasks in your own Jira account. The Agile/Scrum files are project artifacts/templates; update them to reflect the work you actually do.

## Project folder
- `data/customer_churn_sample.csv` — 30 synthetic practice records
- `sql/churn_analysis.sql` — MySQL analysis queries
- `excel/excel_analysis_guide.md` — Excel PivotTable and chart workflow
- `powerbi/powerbi_dashboard_guide.md` — Power BI dashboard instructions
- `documentation/BRD.md` — business requirements
- `documentation/FRD.md` — functional requirements
- `documentation/uat_test_cases.csv` — UAT test cases to execute
- `agile/product_backlog.csv` — backlog items and priorities
- `scrum/sprint_plan.md` — one-week sprint plan and review template
- `jira/jira_setup_guide.md` — how to create Jira project, issues, and workflow
- `report/project_summary_template.md` — final report template

## Suggested workflow
1. Import the CSV into MySQL as `customer_churn`.
2. Run the SQL queries and record results.
3. Follow the Excel guide to make PivotTables and charts.
4. Import the CSV into Power BI and build the dashboard.
5. Create a Jira project and enter the backlog items from `agile/product_backlog.csv`.
6. Use the one-week Scrum sprint plan to plan and review your work.
7. Execute the UAT checklist and update statuses honestly.
8. Complete the project report with actual results and screenshots if desired.

## Dataset note
The dataset is synthetic and small (30 rows), suitable only for learning. It is not real customer data and should not be used to make business decisions.
