# Jira Setup Guide

This ZIP cannot create issues directly in your Jira account. Use the following steps to practice Jira.

## Create project
1. Sign in to Jira.
2. Choose **Projects > Create project**.
3. Choose a Scrum or Kanban template. For this exercise, choose Scrum if available.
4. Name it `Customer Churn Analysis`.
5. Create the project and open its backlog.

## Add issues
Create an Epic named `Customer Churn Analysis Dashboard`, then add tasks from `../agile/product_backlog.csv`:
- Import and review dataset
- Run SQL analysis
- Create Excel summaries
- Build Power BI visuals
- Write BRD and FRD
- Perform UAT
- Prepare final report

For each task, add a description, priority, and acceptance criteria from the CSV. If the Jira UI supports it, associate tasks with the Epic.

## Sprint
1. Create a sprint named `Sprint 1 - Churn Analysis`.
2. Add the tasks you realistically plan to complete.
3. Set a one-week duration and sprint goal.
4. Start the sprint only when ready to work on it.
5. Move issues across the available workflow columns as work progresses.
6. At the end, review completed work and record retrospective notes.

## Evidence for your portfolio
After you actually create the Jira project and use it, capture screenshots of the backlog, sprint board, and completed issues. Do not state Jira was used unless you have completed these steps.
