# Functional Requirements Document (FRD)

- **FR-01:** Dashboard displays customer counts by churn status.
- **FR-02:** Dashboard compares customer counts by contract type and churn status.
- **FR-03:** Dashboard displays average monthly charges by churn status.
- **FR-04:** Dashboard displays average tenure by churn status.
- **FR-05:** User can filter visuals by internet service or payment method.
- **FR-06:** SQL, Excel, and Power BI totals should agree when the same filters are applied.

## Acceptance criteria
- Dashboard opens without errors.
- All required visuals show labels and values.
- Slicers update relevant visuals.
- UAT test outcomes are recorded accurately.
