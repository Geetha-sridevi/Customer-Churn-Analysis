# One-Week Scrum Sprint Plan (Practice Template)

## Sprint goal
Create and validate a basic customer churn analysis report using SQL, Excel, and Power BI, supported by business documentation.

## Suggested sprint duration
One week (adjust dates to your schedule).

## Sprint backlog
- Import and inspect the dataset.
- Run SQL summary queries.
- Create Excel PivotTables and a chart.
- Build Power BI visuals.
- Prepare BRD/FRD.
- Execute UAT checklist.
- Write a short results report.

## Definition of Done
- SQL queries run successfully and results are recorded.
- Excel PivotTables/chart are saved.
- Power BI visuals and slicer are tested.
- BRD/FRD are reviewed.
- UAT actual results and statuses are updated.
- Report states limitations of the synthetic dataset.
